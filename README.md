# MTSK Duyuru

Millî Eğitim Bakanlığı özel motorlu taşıt sürücüleri kursları ve direksiyon eğitimi sınavlarıyla ilgili duyuru, güzergâh, form ve belge bağlantılarını sunan web sitesi.

## Web sitesi

GitHub Pages üzerinden yayımlanır: https://memha.github.io/duyuru/

## Yayınlama

`main` dalına yapılan her gönderim, `.github/workflows/pages.yml` iş akışını tetikler ve siteyi GitHub Pages'e dağıtır.
